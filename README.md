# Personal GitHub Pages site — starter

How to publish:
1. Make sure the repository name is exactly `vivek7557.github.io` (replace with your GitHub username).
2. Put the files in the repository root (index.html and assets/).
3. Commit and push to the `main` branch.
4. Visit `https://vivek7557.github.io/` after a minute.

To use a custom domain:
- Buy a domain like `vivekgiri.io`.
- Add a `CNAME` file (single line) with your domain name (see CNAME file).
- Update the domain's DNS:
  - Add A records pointing to GitHub Pages IPs:
    185.199.108.153
    185.199.109.153
    185.199.110.153
    185.199.111.153
  - Or add a CNAME record pointing to `vivek7557.github.io`.
- In repository Settings → Pages, set the custom domain and enable HTTPS (GitHub will provision).

Customize:
- Edit index.html text and links, replace images, add project tiles linking to GitHub repos or live demos.
- Replace the Formspree URL with your own or use another contact method.
- Consider migrating to Jekyll/Hugo if you want blog features.

Good next steps: edit content, add your projects, and push to the repo.
